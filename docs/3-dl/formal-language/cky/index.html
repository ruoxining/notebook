    Cocke-Younger-Kasami (CYK) Algorithm

    :material-circle-edit-outline: 约 471 个字 :material-clock-time-two-outline: 预计阅读时间 2 分钟

    The Cocke-Younger-Kasami algorithm is a parsing algorithm for the context-free grammars. It employs bottom-up parsing and dynamic programming。

    Standard Form

    Algorithm

    let the input the be a string I consisting of n characters: a1, ... an.
let the grammar contain r nonterminal symbols R1, ..., Rr, with the starting symbol R1.
let P[n,n,r] be an array of booleans. Initialize all elements of P to false.
let back[n,n,r] be an array of lists of backpointing triples. Initialize all elements of back to the empty list.

    for each s = 1 to n
    for each unit production R_v -> a_s
        set P[1, s, v] = true

for each l = 2 to n                                 # length of span
    for each s = 1 to (n-l+l)                       # start of span
        for each p = 1 to l-1                       # partition of span
            for each production R_a                 # R_b R_c
                if P[p,s,b] and P[l-p,s+p,c] then
                    set P[l,s,a] = true
                        append <p,b,c> to back[l,s,a]

if P[n,1,1] is true then
    I is member of language
        return back                                 # by retracing the steps through back, 
                                                    # one can easily construct all possible parsing trees of the string
else
    return "not a member of language"

    Example

    Example grammar:

    S -> NP VP
VP -> VP PP
VP -> V NP
VP -> eats
PP -> P NP
NP -> Det N
NP -> she
V -> eats
P -> with
N -> fish
N -> fork
Det -> a

    Sentence: She eats a fish with a folk.

    We build a CKY table step by step,

    • Step 1 Assign each word a terminal.

      | NP  | V, VP | Det |  N   |  P   | Det |   N   |
| She | eats  |  a  | fish | with |  a  | fork. |

    • Step 2 For each recognized node, continue to assign a label to that matches the current highest label and the next highest label.

      We used the following rules:

      S -> NP, V

      |  S  |  | | | | | |
| NP  | V, VP | Det |  N   |  P   | Det |   N   |
| She | eats  |  a  | fish | with |  a  | fork. |

    Efficiecy Calculation

    The importance of CYK algorithm stems from its high efficiency in certain situations.

    The worst case of its running time is \(\(O(n^3 \dot |G|)\)\), where

    \(\(n\)\) is the length of the parsed string, and

    \(\(|G|\)\) is the size of the CNF grammar.
